# Contributing

Corrections to casting instructions, broken links and current output notes are welcome. Name the template, link to the relevant public page and explain the correction.

Do not submit private photos, payment records, provider keys, internal prompts or unverified claims of speed, quality or popularity. This repository contains documentation and a public catalog, not the hosted applications. Product support involving personal information belongs on the relevant website.

A new entry should include a descriptive scene summary, the required role photos, a useful scene-specific tip, accurate sound notes, and a working live tool link. Check a site before adding it; do not add unrelated promotional links.
